# Wiz Body Lab

Browser-only physical body simulator. No hardware connection, paid API, credentials, or backend is required.

Serve this directory over HTTPS or localhost. For GitHub Pages, select the default branch and /(root). Open the published URL in Safari. Start with Recover → Wave → Start → Complete.

Emergency Stop latches until operator recovery. The screen also demonstrates generation changes, stale command rejection, timeout, obstacle, disconnect and capability rejection. All faults and motion feedback are simulated.

Included files: index.html, app.js, model.js, style.css, generated/v02/{protocol,controller,runtime}.js, README.md, .nojekyll.

Only distributable browser files are included. Generated JavaScript is publicly readable when this repository is public.
