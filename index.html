障害を再現

確認手順
  1. 正常：Recover → Wave → Start → Complete。
  2. 停止保持：Wave → Emergency Stop → Wave（拒否）。Recover後だけ動作可能。
  3. 世代：命令を保存 → Stop → Recover → 保存命令を送信（STALE_GENERATION）。
  4. Timeout：Ready状態でTimeoutを押す → Wave。約0.8秒後に失敗と停止。
  5. Obstacle / Disconnect：動作中に押すとローカル停止。障害除去・再接続だけでは再開せず、Recoverが必要。
  6. Capability：Ready状態でwaveのチェックを外す → Wave（unsupported）。
